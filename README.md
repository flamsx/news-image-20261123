A program that draws one front page summing up the world's news of
Monday 23 November 2026: 35 stories across 7 regions, with a giant date,
a sourced stat strip, three illustrated lead cards, ten numbered cards,
a 22-story digest, a map of where it happened, and a date-check box.

## Run

```sh
python3 main.py   # writes output/entry.png (1024x1024)
```

Requires Python 3 only (standard library — no packages to install). All
text is set in Lexend (OFL); the fonts live in `fonts/` so the render is
self-contained and deterministic.

## Stories

Researched fresh for 23 November 2026 from Reuters, AP, BBC, CNN,
MotoGP.com, The Hindu, ANI and other outlets. Sources are named beside
each story on the page; the full source list with first-report dates is in
the story bank kept with the build notes.
